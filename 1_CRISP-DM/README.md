# Predictive Maintenance Using CRISP-DM

## 1. Business Understanding

### Project Background
Unexpected machine failures can interrupt manufacturing operations and increase maintenance costs. Predictive maintenance uses machine operating data to identify possible failures and support maintenance decisions.

### Business Objective
The goal of this project is to help a manufacturing company identify potential machine failures using sensor and operating data.

### Data Mining Objective
Build a binary classification model to predict whether a machine is in a failure state based on its operating conditions.

### Dataset
- **Name:** AI4I 2020 Predictive Maintenance Dataset
- **Source:** UCI Machine Learning Repository / Kaggle
- **Type:** Synthetic industrial machine data

### Success Criteria
- Compare the performance of a baseline model and at least one additional classification model.
- Evaluate performance using precision, recall, F1-score, and a confusion matrix.
- Pay particular attention to identifying actual machine failures while monitoring false alarms.
- Document limitations and determine whether the model is suitable for a demonstration.

### Expected Outcome
Develop and evaluate a machine failure prediction model and provide a reproducible Google Colab notebook with a simple prediction demonstration.

### Project Methodology
This project follows the six phases of CRISP-DM:

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling
5. Evaluation
6. Deployment

Each phase will include analysis, validation, and documented revisions.
